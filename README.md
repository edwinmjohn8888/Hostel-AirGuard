#  Hostel AirGuard

### ESP32-Based Hostel Ventilation Alert Prototype

## The Problem
In hostel rooms, several students may gather together with the doors and windows closed, especially when the AC is running. This can lead to poor ventilation and possible CO₂ buildup.

I chose this problem after discussing it with a hostel student who was concerned about the air quality in crowded rooms.

## My Solution
Hostel AirGuard is an ESP32-based prototype that demonstrates how a room ventilation warning system could work.

It uses simulated CO₂ readings to trigger LED indicators, buzzer alerts, and practical ventilation suggestions.

## Features
- Green LED — Normal simulated CO₂ level (below 1000 ppm)
- Yellow LED — Ventilation advised (1000–1499 ppm)
- Red LED — High simulated CO₂ level (1500 ppm and above)
- Buzzer warning when the simulated level reaches the red zone
- Ventilation suggestions through the Serial Monitor
- Automatic rising and falling CO₂ simulation

## Components
- ESP32 microcontroller
- 3 LEDs (green, yellow, red)
- 3 resistors (220Ω)
- Buzzer
- Wokwi simulation platform

## Current Limitations
The prototype does not measure actual room CO₂. The readings are generated by software to test the alert system. The thresholds are illustrative, not universal safety limits.

## Future Improvements
- Integrate an SCD40/SCD41 CO₂ sensor for real measurements.
- Add an OLED display for live readings.
- Record readings over time.
